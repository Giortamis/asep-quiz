# ASEPIA – Project Rules

## Σκοπός
Το έγγραφο αυτό καταγράφει τους πρακτικούς και κλειδωμένους κανόνες του ASEPIA, υπό το ανώτατο κανονιστικό `PROJECT_CHARTER.md` στη ρίζα του repository.

## 1. Βασικές Αρχές
- Η εφαρμογή είναι πλατφόρμα προετοιμασίας ΑΣΕΠ.
- Design Freeze → Code Freeze.
- Κάθε νέα λειτουργία λύνει πραγματικό πρόβλημα.

## 2. Αρχιτεκτονική
- Ένας Engine ανά ενότητα.
- Δεν διπλοϋλοποιείται η ίδια λογική.
- Το Study Planner χρησιμοποιεί τους υπάρχοντες Engines.

## 3. Question Engine
- Καμία επανάληψη ερώτησης στο ίδιο τεστ.
- Αποφυγή πρόσφατων ερωτήσεων.
- Ίδιος μηχανισμός σε Διάβασμα, Τεστ, Smart Test και Study Plan.

## 4. CAT Engine
- Adaptive επιλογή.
- Ability ως βασική βαθμολογία.
- Ο χρόνος δεν επηρεάζει το Ability.
- Σύγκριση μόνο με προηγούμενη προσπάθεια.

## 5. Work Behaviour Engine
- Ίδια λογική για άσκηση και προσομοίωση.

## 6. Study Planner
- Δεν δημιουργεί ερωτήσεις.
- Δεν βαθμολογεί.
- Οργανώνει μόνο το πρόγραμμα.

## 7. UI
- Responsive.
- Cross-Platform First.

## 8. Επιχειρηματικό Μοντέλο
- Lifetime License.
- Login.
- Μία ενεργή συνεδρία ανά λογαριασμό.
