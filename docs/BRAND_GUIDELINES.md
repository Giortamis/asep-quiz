# ASEPIA — Brand Guidelines

> **Χαρακτήρας:** Brand Governance Reference  
> **Κατάσταση:** Active — Incomplete Pending Official Asset  
> **Product:** ASEPIA

Το ASEPIA δεν διαθέτει ακόμη οριστικοποιημένο official production logo asset. Το έγγραφο καταγράφει μόνο τις ήδη εγκεκριμένες branding κατευθύνσεις και τα όρια χρήσης μέχρι να εγκριθεί το επίσημο asset.

## 1. Brand Identity Status

- Το όνομα του προϊόντος είναι **ASEPIA**.
- Υπάρχει προσωρινό text wordmark μόνο εκεί όπου έχει ήδη εγκριθεί και υλοποιηθεί.
- Δεν υπάρχει official production SVG ή PNG logo asset στο repository.
- Το V14-005 — Mobile ASEPIA brand integration παραμένει blocked όσο λείπει το επίσημο asset.
- Η ύπαρξη εγκεκριμένης κατεύθυνσης δεν ισοδυναμεί με έτοιμο production branding.

## 2. Logo Governance

Μέχρι την επίσημη έγκριση asset απαγορεύεται:

- επινόηση production logo,
- αυθαίρετη χρήση AI-generated logo ως official asset,
- αποθήκευση προσωρινού logo ως final branding,
- αυθαίρετη αλλαγή αναλογιών,
- δήλωση ανύπαρκτης logo version ως approved.

Placeholder, mockup ή proposal χαρακτηρίζεται πάντα ως τέτοιο.

## 3. Existing Wordmark

Η μόνη επιβεβαιωμένη υπάρχουσα χρήση είναι το text `ASEPIA` μέσα στο desktop Smart Welcome placeholder:

- εμφανίζεται από `901px` και πάνω,
- κληρονομεί το global `Arial, Helvetica, sans-serif`,
- χρησιμοποιεί `#083f78` μέσω του `--blue2`,
- έχει weight `700`, μέγεθος `.82rem` και letter spacing `.18em`,
- συνοδεύεται από σαφή ένδειξη προσωρινού λογοτύπου.

Η καταγραφή δεν μετατρέπει το placeholder σε official asset και δεν εγκρίνει νέο wordmark.

## 4. Mobile Branding Direction

Η ήδη εγκεκριμένη κατεύθυνση προβλέπει:

- icon/logo μόνο μέσα στο μπλε header,
- background του logo ίδιο με το μπλε header,
- `ASEPIA` μέσα στη λευκή Hero Card,
- ακριβώς κάτω από το logo και στην ίδια κατακόρυφη ευθεία,
- μπλε γράμματα,
- χωρίς ανεξάρτητο background, περίγραμμα ή σκιά,
- αναλογίες και typography συνεπείς με το εγκεκριμένο desktop branding.

Αυτή είναι **approved direction**, αλλά η production υλοποίηση περιμένει official asset και δεν αποτελεί μέρος του DOC-007.

## 5. Brand Colors

Η τρέχουσα εφαρμογή επιβεβαιώνει τις εξής βασικές application UI τιμές:

| Ρόλος στην εφαρμογή | CSS token | Τιμή | Brand status |
| --- | --- | --- | --- |
| Κύριο μπλε header/action | `--blue` | `#0b5cab` | Επιβεβαιωμένη μπλε branding κατεύθυνση και ενεργό UI color |
| Σκούρο μπλε text/accent | `--blue2` | `#083f78` | Ενεργό UI/temporary wordmark color |
| Application background | `--bg` | `#f3f6fa` | UI color, όχι αυτόματα official brand color |
| Card background | `--card` | `#ffffff` | UI surface color |
| Main text | `--text` | `#172033` | UI text color |
| Muted text | `--muted` | `#687386` | UI support color |

Τα Registry, CAT, Work, Plan και Help accents είναι section UI colors. Δεν χαρακτηρίζονται από το παρόν document ως official logo palette. Το τελικό official brand palette παραμένει incomplete μέχρι την έγκριση asset/specification.

## 6. Typography & Brand

- Η υπάρχουσα εφαρμογή χρησιμοποιεί `Arial, Helvetica, sans-serif`.
- Το προσωρινό desktop wordmark χρησιμοποιεί την ίδια κληρονομημένη typography με αυξημένο letter spacing.
- Δεν εγκρίνεται νέα commercial font.
- Δεν αποθηκεύεται ή ενσωματώνεται νέο font asset στο DOC-007.
- Η τελική logo typography πρέπει να επιβεβαιωθεί μαζί με το official asset.

## 7. Pending after official asset approval

Οι παρακάτω είναι μόνο κατηγορίες μελλοντικών παραδοτέων:

- Primary logo
- Icon
- Horizontal / vertical version, αν εγκριθεί
- Light version
- Dark/blue version
- Monochrome version
- SVG
- PNG

**Δεν θεωρούνται υπάρχοντα ή εγκεκριμένα μέχρι να παραδοθούν πραγματικά assets.**

## 8. Clear Space — Pending

`Pending official logo specification`

Δεν ορίζεται αριθμητικός κανόνας πριν από την έγκριση του official logo.

## 9. Minimum Size — Pending

`Pending official asset testing`

Δεν ορίζεται minimum size σε px ή mm χωρίς πραγματικό asset testing.

## 10. Incorrect Usage

Δεν επιτρέπονται:

- stretch ή distortion,
- αλλαγή αναλογιών,
- μη εγκεκριμένο recoloring,
- πρόσθεση shadow ή effects,
- χρήση πάνω σε background με ανεπαρκή αναγνωσιμότητα,
- δημιουργία νέας variant χωρίς έγκριση,
- χρήση προσωρινού asset ως official.

## 11. Brand Asset Storage

Όταν εγκριθεί official asset:

- θα προστεθεί οργανωμένα στο repository,
- θα οριστεί σαφές canonical filename και path,
- θα ενημερωθεί το `BRAND_GUIDELINES.md`,
- το V14-005 θα μπορεί να επανεξεταστεί μέσω του κατάλληλου Specification.

Το DOC-007 δεν δημιουργεί asset folder ή placeholder files.

## 12. Brand Approval

Κάθε branding change απαιτεί:

1. Product Owner decision.
2. Design Freeze.
3. Specification.
4. Asset verification.
5. UI validation.
6. Product Approval.

Το Codex και άλλα AI εργαλεία δεν αποφασίζουν branding.

## 13. Τι δεν είναι το BRAND_GUIDELINES.md

Δεν είναι logo creation brief, asset-generation Sprint, redesign, marketing strategy ή άδεια ολοκλήρωσης του V14-005.
