# VISION.md

# ASEPIA
## Vision Document

## Αποστολή
Να δημιουργηθεί η κορυφαία ελληνική πλατφόρμα προετοιμασίας για τον Πανελλήνιο Γραπτό Διαγωνισμό ΑΣΕΠ.

## Όραμα
Ο υποψήφιος να μπορεί να προετοιμαστεί πλήρως μέσα από μία μόνο εφαρμογή.

## Βασικοί Πυλώνες

1. Μητρώο Ερωτήσεων
- Πλήρης κάλυψη του επίσημου μητρώου.
- Έξυπνη εξάσκηση.
- Προσωποποιημένη πρόοδος.

2. Μέθοδος CAT
- Ρεαλιστική προσομοίωση.
- Ability Score.
- Ιστορικό προόδου.

3. Εργασιακές Συμπεριφορές
- Εξάσκηση.
- Πλήρης προσομοίωση.
- Ανατροφοδότηση.

4. Study Planner
- Προσωπικό πρόγραμμα μελέτης.
- Αυτόματη προσαρμογή.
- Ημερήσιοι στόχοι.

5. Βοήθεια
- Οδηγός ΑΣΕΠ.
- Οδηγός Εφαρμογής.
- Συχνές ερωτήσεις.

## Πλατφόρμες

- Android
- iOS
- Web

Μία κοινή βάση κώδικα.

## Επιχειρηματικό μοντέλο

- Lifetime License
- Login
- Cloud Sync
- Μία ενεργή συνεδρία

## Στόχος

Η εφαρμογή να αποτελεί το σημείο αναφοράς για κάθε υποψήφιο ΑΣΕΠ στην Ελλάδα.
